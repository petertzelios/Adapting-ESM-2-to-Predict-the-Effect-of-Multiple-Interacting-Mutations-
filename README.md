# Adapting ESM-2 to Predict the Effect of Multiple Interacting Mutations

Class project for CBMF 4761. The goal of the project is to use frozen ESM-2 embeddings to predict the impact of multiple simultaneous mutations in the GB1 dataset.

The project evaluates whether lightweight secondary models trained on frozen ESM-2 embeddings can improve prediction of multiple interacting mutations. The main workflow has two stages:

1. **Feature engineering from ESM-2 embeddings**: compare global sequence summaries, mutation-site embeddings, and local mutation-window embeddings.
2. **Secondary model architecture search**: compare flat ridge/MLP models against fused models that process global and local features separately.

## Notebooks

### `CBMF4761_project_premid_featureengineering_flatridgemlp.ipynb`

Original pre-midpoint notebook. This notebook contains the initial FLIP/GB1 loading, ESM-2 embedding generation/loading, feature engineering experiments, flat ridge regression experiments, and flat MLP secondary model experiments. It includes additional feature-selection strategies and hyperparameter grids excluded from the final report for brevity.

### `CBMF4761_project_postmid_secondarymodel_fused.ipynb`

Post-midpoint secondary model exploration. This notebook contains the fused-model work, including global/local feature preparation and sweeps over fused MLP, fused CNN, and fused attention-style local encoders. It includes additional hyperparameter grids excluded from the final report for brevity.

### `CBMF4761_project_GB1_ESM2_quickstart_best_CNN.ipynb`

Small reproduction notebook intended for quick grading/review. It loads the processed features or full embeddings, reconstructs the final global mean + local mutation-window representation, and trains the best fused CNN and best fused attention configurations across all three FLIP splits. It also generates the train/test loss curves used for Figure 7 in the final report.

Best CNN configuration used in the quickstart notebook:

- Global branch: `(128, 64)` hidden dimensions
- Local branch: 1D CNN with `384` channels, kernel size `7`, and `1` layer
- Fusion branch: `(64,)` hidden dimensions
- Dropout: `0.1`
- Optimizer: AdamW
- Learning rate: `1e-3`
- Weight decay: `1e-3`
- Batch size: `128`

Best attention configuration used in the quickstart notebook:

- Global branch: `(128, 64)` hidden dimensions
- Local branch: Transformer-style attention encoder with attention dimension `128`, `8` heads, `1` layer, and mean pooling
- Fusion branch: `(64,)` hidden dimensions
- Dropout: `0.1`
- Optimizer: AdamW
- Learning rate: `1e-3`
- Weight decay: `1e-3`
- Batch size: `128`

## Data files

The quickstart notebook expects data files in the `data/` directory. The large `.pt` files are not committed to GitHub because of file-size limits, but they can be downloaded from the Google Drive links below.

### Preferred quickstart file: `data/gb1_features_k5.pt`

This is the most convenient file because it avoids regenerating or reprocessing full ESM-2 embeddings. It should be a PyTorch-saved dictionary containing:

```python
{
    "df_full": ...,        # pandas DataFrame or dict-like metadata table
    "X_seq_mean": ...,     # shape: (n_samples, 640)
    "X_window_k5": ...,    # shape: (n_samples, n_window_positions, 640)
    "feature_info": ...    # optional metadata dictionary
}
```

The metadata table includes:

- `fitness`
- `one_vs_rest`
- `two_vs_rest`
- `three_vs_rest`

The split columns contain `train` and `test` labels aligned with the official FLIP train-test data splits.

Download link: https://drive.google.com/file/d/1Z2G2VZUG9z-pbq_83EUB6gDKX2OvhFVc/view?usp=share_link

### Full embedding file: `data/gb1_esm2_embeddings.pt`

If there is a failure using `gb1_features_k5.pt`, the quickstart notebook can rebuild features from the full per-residue ESM-2 embedding file. The notebook supports a dictionary with the following expected keys or close variants:

- `X_residue` or `X` or `embeddings` or `representations`
- `Variants` / `variant` / `variants`
- `sequence` / `Sequence` / `sequences`
- `fitness` / `Fitness`
- `one_vs_rest`
- `two_vs_rest`
- `three_vs_rest`

Download link: https://drive.google.com/file/d/150etNqYjLZp0_SJljnLBiNPibjKgqX3g/view?usp=sharing

## Running the quickstart notebook

1. Clone or download this repository.
2. Place `gb1_features_k5.pt` in the `data/` folder. If using `gb1_features_k5.pt` produces an error, place `gb1_esm2_embeddings.pt` in the `data/` folder instead.
3. Open `notebooks/CBMF4761_project_GB1_ESM2_quickstart_best_CNN.ipynb` in Google Colab or Jupyter.
4. Run all cells.

The quickstart notebook trains the best CNN and attention models on each split, saves per-split summaries, saves per-epoch training histories, saves test-set predictions, and generates the training/test loss comparison figure used in the report.

### Summary files

- `best_cnn_split_results.csv`: one row per FLIP split for the selected fused CNN model.
- `best_attention_split_results.csv`: one row per FLIP split for the selected fused attention model.

These files summarize the main quickstart model results. Typical columns include:

- `model`: model family, e.g. fused CNN or fused attention
- `split`: FLIP split name (`one_vs_rest`, `two_vs_rest`, or `three_vs_rest`)
- `n_train`: number of training examples in that split
- `n_test`: number of test examples in that split
- `best_epoch`: epoch with the best test Spearman correlation during the quickstart run
- `best_spearman`: best test Spearman correlation
- `best_train_loss`: training MSE at the best epoch
- `best_test_loss`: test MSE at the best epoch
- `best_train_mae`: training MAE at the best epoch
- `best_test_mae`: test MAE at the best epoch

Spearman correlation is the primary performance metric used in the report. Loss and MAE are included as additional training diagnostics.

### History files

The `history_<split>.csv` files contain one row per training epoch for each model/split. Typical columns include:

- `epoch`: training epoch
- `train_loss`: average optimization loss during the training loop
- `train_eval_loss`: MSE when evaluating the model on the training set after the epoch
- `test_loss`: MSE on the test set after the epoch
- `train_spearman`: Spearman correlation on the training set
- `test_spearman`: Spearman correlation on the test set
- `train_mae`: MAE on the training set
- `test_mae`: MAE on the test set

These files are mainly used to generate the training/test loss curves in Figure 7 of the report and to inspect optimization stability.

### Prediction files

The `predictions_<split>.csv` files contain the observed and predicted test-set fitness values for each split. Typical columns include:

- `y_test`: observed GB1 fitness value
- `pred_test`: model-predicted fitness value

These files allow downstream inspection of model predictions without rerunning training.

### Figure files

The `outputs/figures/` directory contains the loss-curve figure produced by the quickstart notebook in both PNG and PDF form:

- `quickstart_cnn_attention_train_test_loss_by_split.png`
- `quickstart_cnn_attention_train_test_loss_by_split.pdf`

This figure compares the best CNN and attention models across the three FLIP splits. Each panel is a different split, color indicates model family, line style indicates train versus test loss, and vertical dotted lines mark the epoch with the best test Spearman correlation for each model.
