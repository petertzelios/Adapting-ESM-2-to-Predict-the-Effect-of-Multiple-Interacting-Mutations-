# Adapting ESM-2 to Predict the Effect of Multiple Interacting Mutations

Class project for CBMF 4761. Goal of the project is to use frozen ESM-2 embeddings to predict the impact of multiple simultaneous mutations in the GB-1 dataset. 

The project evaluates whether lightweight secondary models trained on frozen ESM-2 embeddings can improve prediction of multiple interacting mutations. The main workflow has two stages:

1. **Feature engineering from ESM-2 embeddings**: compare global sequence summaries, mutation-site embeddings, and local mutation-window embeddings.
2. **Secondary model architecture search**: compare flat ridge/MLP models against fused models that process global and local features separately.

## Notebooks

### `CBMF4761_project_premid_featureengineering_flatridgemlp.ipynb`

Original pre-midpoint notebook. This notebook contains the initial FLIP/GB1 loading, ESM-2 embedding generation/loading, feature engineering experiments, flat ridge regression experiments, and flat MLP secondary model experiments. Contains feature selection strategies and hyperparameter grids exluded from the final report for the sake of brevity.

### `CBMF4761_project_postmid_secondarymodel_fused.ipynb`

Post-midpoint secondary model exploration. This notebook contains the fused-model work, including global/local feature preparation and sweeps over fused MLP, fused CNN, and fused attention-style local encoders. Contains hyperparemeter grids excluded from the final report for the sake of brevity.

### `CBMF4761_project_GB1_ESM2_quickstart_best_CNN.ipynb`

Small reproduction notebook intended for quick grading/review. It loads the processed features or full embeddings, reconstructs the final global mean + local mutation-window representation, and trains the best fused CNN and best fused attention configurations across all three FLIP splits. It also generates the train/test loss curves used for Figure 7 in the final report.

Best CNN configuration used in the quickstart notebook:

- Global branch: `(128, 64)` hidden dimensions
- Local branch: 1D CNN with `384` channels, kernel size `7`, and `1` layer
- Fusion branch: `(64,)` hidden dimensions
- Dropout: `0.1`
- Optimizer: AdamW
- Learning rate: `1e-3`
- Weight decay: `1e-3`
- Batch size: `128`

## Data files

The quickstart notebook expects data files in the `data/` directory.

### Preferred quickstart file: `data/gb1_features_k5.pt`

This is the most convenient file because it avoids regenerating or reprocessing full ESM-2 embeddings. It should be a PyTorch-saved dictionary containing:

```python
{
    "df_full": ...,        # pandas DataFrame or dict-like metadata table
    "X_seq_mean": ...,     # shape: (n_samples, 640)
    "X_window_k5": ...,    # shape: (n_samples, n_window_positions, 640)
    "feature_info": ...    # optional metadata dictionary
}
```

The metadata table includes:

- `fitness`
- `one_vs_rest`
- `two_vs_rest`
- `three_vs_rest`

The split columns should contain `train` and `test` labels which are aligned with the official FLIP train-test data splits.

This file was too large to upload to github so please find in google drive at: https://drive.google.com/file/d/1Z2G2VZUG9z-pbq_83EUB6gDKX2OvhFVc/view?usp=share_link

### Full embedding file: `data/gb1_esm2_embeddings.pt`

If there is a failure in using the `gb1_features_k5.pt`, the quickstart notebook can rebuild features from the full per-residue ESM-2 embedding file. The notebook supports a dictionary with the following expected keys or close variants:

- `X_residue` or `X` or `embeddings` or `representations`
- `Variants` / `variant` / `variants`
- `sequence` / `Sequence` / `sequences`
- `fitness` / `Fitness`
- `one_vs_rest`
- `two_vs_rest`
- `three_vs_rest`

This file was too large to upload to github so please find in google drive at: https://drive.google.com/file/d/150etNqYjLZp0_SJljnLBiNPibjKgqX3g/view?usp=sharing.

## Running the quickstart notebook

1. Clone or download this repository.
2. Place `gb1_features_k5.pt` in the `data/` folder. If using the `gb1_features_k5.pt` has an error for some reason, place `gb1_esm2_embeddings.pt` in the `data/` folder.
3. Open `notebooks/CBMF4761_project_GB1_ESM2_quickstart_best_CNN.ipynb` in Google Colab or Jupyter.
4. Run all cells.

The notebook writes results to:

```text
outputs/quickstart_best_cnn/
├── best_cnn_split_results.csv
├── history_one_vs_rest.csv
├── history_two_vs_rest.csv
├── history_three_vs_rest.csv
├── predictions_one_vs_rest.csv
├── predictions_two_vs_rest.csv
└── predictions_three_vs_rest.csv
```
